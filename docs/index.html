How a tile becomes a verdict

1. The true sky

Point sources and Gaussian blobs placed at random, then observed through MeerKAT's uv coverage.

2. What the telescope gives you

The dirty image: every source smeared by the point spread function, plus noise. This is all the model ever sees.

3. Tile, find the peak, test it

Each tile's brightest local peak is kept if it rises 2σ above a SExtractor-style background mesh.

4. One dot product decides

The SVM's learned weights: a bright core minus a dark ring. Coral pulls towards point source, lilac towards extended.

The linear SVM held up as the images got harder

About this demo

The image is the unseen test image from the thesis's third experiment, simulated with ducc0 from MeerKAT uv coverage: 1,000 point sources and 100 extended sources. The ground truth was rebuilt from the simulation's random seed and matches the saved image exactly.

The model was retrained with the thesis settings (linear kernel, C = 10, three-fold grid search) on the Experiment 3 training cutouts. Unlike the original test script, it scales unseen data with the training scaler. It scores 89.5% on all 1,275 unseen cutouts; the thesis reported 90.2% on a 765-cutout subset.

The classifier is binary: point source or not. In this image almost everything that isn't a point source is extended emission, so the second class is shown as "Extended". Empty tiles are filtered out before the model is asked, by the detection threshold.

Everything runs in your browser. Ground truth marks a detection correct when a true point source lies within 2 pixels of its peak, or when it was called extended and no point source is there.
